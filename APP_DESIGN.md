IDRICI CRAFT — Mobile App Design

1. Product Identity

- Official application name: IDRICI CRAFT
- Platform: Android
- Interface: Original design created specifically for this project.
- The application must not copy the desktop interface of Craft Anything.

2. Visual Direction

- Modern, premium, clean and technical.
- Dark graphite background.
- Subtle emerald and cyan accents.
- High contrast and readable typography.
- Rounded cards and clear navigation.
- Responsive layout designed for mobile screens.

3. Main Screen

The home screen must display:

- IDRICI CRAFT branding at the top.
- A short welcome message.
- A large input area for a website URL, repository URL, or project description.
- A primary action to start studying the target.
- A task progress area.
- Recent projects and tasks.

4. Main Workflow

The application must organize its workflow into five stages:

1. STUDY — inspect the target.
2. PLAN — prepare the implementation plan.
3. BUILD — create the new project.
4. CHECK — compare the result with the target.
5. REFINE — improve the result.

Each stage must have a clear status and progress indicator.

5. Navigation

The planned mobile navigation contains:

- Home
- Projects
- Tasks
- Files
- Settings

6. User Experience

- Arabic is the primary interface language.
- Support right-to-left layout.
- English and French may be added later.
- Large touch-friendly buttons.
- Clear loading, success, and error states.
- Never display fake progress or claim a task is complete before the server confirms it.

7. Important Rule

The IDRICI CRAFT interface is an original product design. Its identity, logo, colors, navigation, and mobile experience will be developed independently.

8. Implementation Status

This document defines the planned design. It does not mean that the interface has already been implemented.
