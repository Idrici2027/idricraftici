IDRICI CRAFT — Application Design Specification

1. Design Vision

IDRICI CRAFT must have an original, modern and professional user interface.

The design must be developed independently and must not copy the Craft Anything interface.

2. Brand Identity

- Official application name: IDRICI CRAFT.
- The application name must appear clearly in the interface.
- Use a consistent visual identity.
- Maintain a modern, clean and recognizable appearance.
- The application icon and branding must remain consistent.

3. Design Principles

- Mobile-first design.
- Simple and intuitive navigation.
- Modern interface components.
- Clear visual hierarchy.
- Smooth and responsive interactions.
- Accessible text and controls.
- Consistent spacing and typography.

4. Language and Direction

- Arabic is the primary interface language.
- Full right-to-left (RTL) support is required.
- Layout must correctly support Arabic text.
- Additional language support may be added later.

5. Main Application Screens

5.1 Home Screen

The home screen should provide:

- IDRICI CRAFT branding.
- New project creation.
- Project source selection.
- Recent projects.
- Access to application settings.

5.2 Project Creation

Users must be able to start a project using:

- A website URL.
- A GitHub repository URL.
- A written project description.

5.3 Project Workspace

The workspace should provide:

- Project information.
- Current workflow stage.
- Task progress.
- Generated files.
- Execution logs.
- Error reports.

5.4 AI Workflow Screen

Display the five workflow stages:

1. STUDY
2. PLAN
3. BUILD
4. CHECK
5. REFINE

Only show progress confirmed by the backend.

5.5 Settings Screen

Provide:

- Language settings.
- Account settings.
- Application information.
- Theme preferences.

6. Navigation

Navigation must be designed for comfortable mobile use.

The interface should provide clear access to the main application sections without unnecessary complexity.

7. User Experience

- Display clear loading states.
- Provide meaningful error messages.
- Confirm important actions.
- Preserve project history.
- Avoid fake progress indicators.
- Support different Android screen sizes.

8. Technical Requirements

- Responsive Android interface.
- Proper RTL layout support.
- Backend API integration.
- Secure authentication.
- Efficient network communication.
- Maintainable UI components.

9. Design Independence

All interface layouts, navigation patterns, branding elements and visual components must be original to IDRICI CRAFT.

Craft Anything is a functional and technical reference, not a visual design template.
