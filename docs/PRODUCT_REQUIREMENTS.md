IDRICI CRAFT — Product Requirements

1. Product Overview

IDRICI CRAFT is an Android-first AI application inspired by the open-source Craft Anything project.

It aims to let users describe an application or digital product in natural language and guide an AI-powered workflow to plan, build, test, and refine it.

The product will have its own original identity, interface, architecture, and implementation under the IDRICI CRAFT brand.

2. Product Goals

- Provide an easy way to create applications using natural language.
- Support users without advanced programming knowledge.
- Transform user ideas into structured development tasks.
- Provide visibility into the AI development process.
- Allow users to review and improve generated results.
- Build a secure and extensible platform.

3. Target Platform

Primary platform: Android.

The interface must be mobile-first and optimized for smartphone screens.

Future platforms may include web and desktop.

4. User Input

Users should be able to provide:

- Project name.
- Project description.
- Application type.
- Requirements and desired features.
- Reference repository URL, when available.
- Additional instructions.

5. Core Workflow

The application will use five main stages:

STUDY

Understand the user's idea, requirements, and available references.

PLAN

Create a structured implementation plan and identify required components.

BUILD

Generate or modify project files and implementation code.

CHECK

Review generated work, detect errors, and run available tests.

REFINE

Improve the result based on detected problems and user feedback.

6. Project Management

Users should be able to:

- Create projects.
- View project status.
- Review workflow progress.
- Access generated files.
- Review previous operations.
- Continue unfinished projects.

7. AI Capabilities

The AI system should support:

- Natural-language understanding.
- Project analysis.
- Technical planning.
- Code generation.
- File creation and modification.
- Error analysis.
- Iterative improvements.

These capabilities must be implemented through a controlled backend architecture.

8. User Interface

The application must use the original IDRICI CRAFT design.

Requirements:

- Mobile-first layout.
- Arabic RTL support.
- Clear navigation.
- Consistent typography and spacing.
- Visible project progress.
- Readable code and task information.
- IDRICI CRAFT branding inside the application.

9. Backend Requirements

The backend should provide:

- API endpoints for the Android application.
- Workflow orchestration.
- AI model integration.
- Project and task management.
- File storage and retrieval.
- Execution and testing coordination.

10. Security Requirements

- Protect API credentials and secrets.
- Authenticate users and authorize project access.
- Isolate code execution environments.
- Validate user input.
- Prevent unauthorized file and system access.
- Record important operations.

11. Reliability

The system should:

- Report task status accurately.
- Handle failed operations safely.
- Preserve project data.
- Provide useful error messages.
- Allow interrupted workflows to resume where possible.

12. Acceptance Criteria

The product will be considered ready for an initial release when:

- Users can create and manage projects.
- Users can submit project descriptions.
- The five workflow stages are represented.
- The backend can process project tasks.
- Generated files can be reviewed.
- Errors and workflow status are visible.
- Core security requirements are implemented.
- The Android application works on supported devices.

13. Current Project Status

Status: PLANNING

This document defines product requirements. It does not indicate that the listed features have already been implemented.
