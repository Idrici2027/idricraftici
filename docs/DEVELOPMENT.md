# IDRICI CRAFT - Development Guide

## 1. Project Overview

IDRICI CRAFT is an AI-powered application based on the open-source Craft Anything project.

The goal is to provide the same core functionality through a dedicated mobile-friendly application.

## 2. Development Principles

- Preserve the original core functionality.
- Maintain clean and modular code.
- Prioritize mobile compatibility.
- Keep the application responsive.
- Avoid unnecessary dependencies.
- Maintain security and reliability.

## 3. Development Workflow

1. Review existing source code.
2. Identify the required changes.
3. Implement changes without breaking existing features.
4. Test modified components.
5. Review errors and logs.
6. Verify the final build.

## 4. User Interface

The IDRICI CRAFT interface will be independently designed.

The application must maintain its own visual identity, branding, navigation, and user experience.

## 5. Code Quality

- Use clear naming conventions.
- Avoid duplicated code.
- Handle errors properly.
- Keep configuration separate from source code.
- Document important components.

## 6. Testing

Every significant modification must be tested before integration.

Testing must cover:

- Application startup.
- Core functionality.
- API communication.
- Mobile responsiveness.
- Error handling.
- Build stability.

## 7. Project Maintenance

All changes must be tracked through Git.

The main branch must contain stable and verified project updates.
